# Contributing to Fluxquint™

Fluxquint™ is presently maintained as a proprietary project. Contributions require prior approval and a written contributor agreement assigning the necessary intellectual-property rights.

Approved changes should:

1. preserve deterministic replay behaviour;
2. include tests for rule changes;
3. use Fluxquint™ in all user-facing branding;
4. document asset provenance;
5. preserve keyboard, touch and accessibility support;
6. explain ruleset-version impact in the pull request.
