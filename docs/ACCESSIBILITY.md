# Fluxquint™ Accessibility

Fluxquint™ is designed so no critical game state depends on colour, motion or sound alone.

Implemented support:

- visible numerals and optional geometric symbols for every rank;
- high-contrast interface mode;
- reduced-motion mode;
- generated sound cues with independent disable control;
- keyboard, mouse and touch input;
- visible trajectory and capture prediction;
- semantic buttons and accessible labels for every lattice cell;
- responsive layout for mobile and desktop;
- system-level reduced-motion preference detection.

Future validation should include screen-reader journey testing and playtesting with users who have colour-vision, motor and numeracy differences.
