# Fluxquint™ Asset Provenance

All current visual assets are original vector or programmatic assets created for Fluxquint™:

- `public/icon.svg` — original magnetic Core emblem.
- `public/og.svg` — original social preview composition.
- `public/icon-192.png` and `public/icon-512.png` — generated from the same original identity.
- Interface icons — original inline SVG path implementation for generic functional symbols.
- Audio — generated at runtime using Web Audio oscillators; no recorded third-party sound files.
- Typography — operating-system font stack; no bundled third-party font files.
